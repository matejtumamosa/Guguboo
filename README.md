# Guguboo

Pokojný sprievodca tehotenstvom a prvým rokom bábätka – https://guguboo.com

- `index.html` – úvodná stránka (formulár „Chcem testovať“ cez Netlify Forms), `sukromie.html`, `dakujeme.html`
- `app.html` – appka (Master), údaje len v telefóne (kľúče `guguboo-m-*`), dá sa pridať na plochu (`manifest.webmanifest`, `sw.js`)

Vývoj prebieha vo vetve `v2` v priečinku `guguboo-master/` (pozri `CLAUDE.md` vo vetve `v2`). Na guguboo.com ide cez pull request do `main`.
